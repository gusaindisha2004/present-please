# Screenshots for the root README

The root `README.md` expects four PNGs in this folder. Capture them at a
**1440x900** browser window, in light mode, with the demo data seeded
(not your own account — these are published).

| File | What to capture |
| --- | --- |
| `landing.png` | `/` — the full hero, down to "Choose your role to get started". |
| `teacher-timetable.png` | `/t/timetable` — a week with classes on at least two days, so the grid, the branch/year labels and the status badges all show. |
| `attendance-review.png` | `/t/attendance/<subjectId>?classId=<classId>` after a face or voice scan — the editable present/absent table with confidence values. This is the signature screen; it is worth staging properly. |
| `student-dashboard.png` | `/s` — overall attendance, the remark, and the per-subject percentages. |

Crop out anything with a real email address in it. PNG, and keep each
file under ~500 KB so the repo stays light.
